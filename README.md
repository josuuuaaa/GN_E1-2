# Python 콘솔 퀴즈 게임

Python 기초 문법과 Git 사용법 등을 객관식 문제로 학습할 수 있는 **터미널 기반 퀴즈 프로그램**입니다. 사용자는 문제를 풀거나 직접 새로운 문제를 등록할 수 있으며, 퀴즈 목록과 최고 점수를 확인할 수 있습니다. 등록한 문제와 최고 점수는 `state.json`에 저장되어 재실행 후에도 유지됩니다.

## 1. 프로젝트 개요

- **개발 언어:** Python 3
- **실행 환경:** 터미널(콘솔)
- **사용 라이브러리:** Python 표준 라이브러리 `os`, `json` (별도 패키지 설치 불필요)
- **프로그램 구성:** `Quiz` 클래스(개별 문제), `QuizGame` 클래스(게임 진행 및 데이터 관리)

## 2. 퀴즈 주제와 선정 이유

**주제:** Python 기초 문법과 개발 기초 지식

Python의 출력, 입력, 문자열 처리, 자료형 변환, 조건문처럼 프로그래밍을 시작할 때 자주 사용하는 개념을 중심으로 기본 문제 5개를 구성했습니다. 기초 지식을 객관식 문제로 반복 확인하면서 익히고, 문제 등록 기능을 활용해 Git 등 다른 개발 주제로도 학습 범위를 확장하기 위해 이 주제를 선택했습니다.

## 3. 실행 방법

1. **Python 3**가 설치되어 있는지 확인합니다.

   ```bash
   python --version
   ```

2. 프로젝트 폴더에서 프로그램을 실행합니다.

   ```bash
   python main.py
   ```

   > 실행 파일명이 다른 경우 실제 `.py` 파일명으로 바꾸어 실행합니다. 일부 환경에서는 `python` 대신 `python3` 또는 Windows의 `py` 명령어를 사용합니다.

3. 화면에 표시되는 메뉴 번호를 입력합니다.

   ```text
   1. 퀴즈 풀기
   2. 퀴즈 추가
   3. 퀴즈 목록
   4. 최고 점수 확인
   5. 종료
   ```

처음 실행할 때 `state.json`이 없으면 기본 퀴즈 5개로 시작합니다. 게임 종료 시 파일을 저장하여 다음 실행에서 다시 불러옵니다.

## 4. 기능 목록

| 기능 | 설명 |
| --- | --- |
| 퀴즈 풀기 | 등록된 문제를 순서대로 출제하고 1~4번 답안을 입력받아 채점합니다. 정답 여부와 해설을 표시합니다. |
| 퀴즈 추가 | 문제, 보기 4개, 정답 번호, 해설을 입력하여 새로운 퀴즈를 등록하고 저장합니다. |
| 퀴즈 목록 | 등록된 퀴즈의 문제, 보기 개수, 정답 번호를 표시합니다. |
| 최고 점수 확인 | 완료한 퀴즈 중 가장 높은 정답 수를 표시합니다. 최초에는 기록이 없습니다. |
| 데이터 저장/불러오기 | 퀴즈 목록과 최고 점수를 JSON 파일로 저장하고 실행할 때 불러옵니다. |
| 입력값 검사 | 숫자 입력에서 공백 제거, 빈 값, 숫자가 아닌 값, 허용 범위를 벗어난 값을 검사하고 안내합니다. |
| 안전 종료 | `Ctrl+C` 또는 EOF 입력 시 예외를 처리하고, 가능한 경우 종료 직전에 데이터를 저장합니다. |
| 파일 오류 대응 | 저장 파일이 없거나 읽기·형식 오류가 있으면 안내하고 기본 퀴즈 데이터로 시작합니다. |

> **점수 기준:** 맞힌 문제 1개당 1점이며, 퀴즈를 **끝까지 완료한 경우**에만 최고 점수를 비교·갱신합니다. 중간 종료한 풀이의 점수는 최고 점수에 반영되지 않습니다.

## 5. 파일 구조

```text
프로젝트 루트/
├── main.py                  # 퀴즈 게임 전체 소스코드
├── state.json               # 퀴즈 목록 및 최고 점수 저장 파일(실행 시 생성되지만 예시를 위해 추가함)
└── README.md                # 프로젝트 설명서
```

> 위 구조는 제공된 소스 파일명을 기준으로 작성했습니다. GitHub 저장소에 올린 Python 파일명이 다르면 구조와 실행 명령어의 파일명을 동일하게 수정하세요.

## 6. 데이터 파일 (`state.json`)

- **경로:** Python 실행 파일과 같은 폴더의 `state.json` (프로젝트 루트에 실행 파일이 있을 경우 프로젝트 루트)
- **역할:** 등록된 퀴즈와 최고 점수를 프로그램 종료 후에도 유지
- **인코딩:** UTF-8
- **저장 방식:** JSON 형식으로 임시 파일(`state.json.tmp`)을 먼저 작성한 다음 `os.replace()`로 교체
- **예외 처리:** 파일이 없으면 기본 문제로 시작하며, 읽기 오류 또는 유효하지 않은 저장 데이터가 발견되면 안내 메시지를 출력하고 기본 문제로 시작합니다. 이후 저장에 성공하면 기존 파일은 현재 데이터로 교체됩니다.

### 데이터 스키마

| 키 | 자료형 | 의미 |
| --- | --- | --- |
| `quizzes` | 배열(Array) | 퀴즈 객체 목록 |
| `quizzes[].question` | 문자열(String) | 문제 내용 |
| `quizzes[].choices` | 문자열 배열(길이 4) | 객관식 보기 4개 |
| `quizzes[].answer` | 정수(Integer) | 정답 번호(1~4) |
| `quizzes[].explanation` | 문자열(String) | 정답 해설 |
| `best_score` | 정수 또는 `null` | 최고 정답 수, 아직 퀴즈를 완료하지 않았으면 `null` |

### 저장 예시

```json
{
  "quizzes": [
    {
      "question": "Python에서 화면에 글자를 출력할 때 사용하는 함수는?",
      "choices": ["echo()", "console.log()", "print()", "write()"],
      "answer": 3,
      "explanation": "print() 함수는 화면에 값을 출력할 때 사용합니다."
    }
  ],
  "best_score": null
}
```

> 위 JSON은 **스키마 설명용 예시**이며, 실제 첫 실행 시에는 기본 문제 5개가 구성됩니다. `state.json`이 이미 존재한다면 저장된 퀴즈 목록을 불러옵니다.

## 7. 종료 및 오류 처리

- 메뉴에서 `5`를 선택하면 정상 종료합니다.
- 실행 도중 `Ctrl+C`를 누르거나 입력 스트림이 종료되어 `EOFError`가 발생하면 안내 후 저장을 시도하고 종료합니다.
- 퀴즈 추가 중 입력이 끝나지 않은 문제는 등록되지 않으며, 등록이 완료된 퀴즈만 저장 대상입니다.
- 저장 도중 오류가 발생하면 안내 메시지를 출력합니다.

## 8. GitHub 최종 업로드

README를 작성한 후 변경 파일을 확인하고 커밋·푸시합니다.

```bash
git status
git add README.md
git commit -m "docs: README에 프로젝트 설명 및 실행 방법 추가"
git push
```

> 새 브랜치의 최초 푸시라면 `git push -u origin <브랜치명>`을 사용하세요. `state.json`에 개인 정보나 민감한 문제 내용이 들어 있는 경우 업로드 전 확인해야 합니다.

### 커밋 메시지 규약 (Commit Message Convention)

| 타입 | 설명 |
| :--- | :--- |
| **feat** | 새로운 기능 추가 |
| **fix** | 버그 수정 |
| **docs** | 문서 수정 (README 등) |
| **style** | 코드 스타일 수정 (포매팅, 세미콜론 누락 등, 기능 변경 없음) |
| **refactor** | 코드 구조 개선 (리팩토링) |
| **test** | 테스트 코드 추가 또는 수정 |
| **chore** | 빌드 설정, 패키지 매니저 설정 등 기타 작업 |
